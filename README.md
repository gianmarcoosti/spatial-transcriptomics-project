# Computational Analysis of Spatial Gene Expression in Human Melanoma Tissue

## Spatial Transcriptomics Analysis of Human Melanoma (10x Visium)

This project demonstrates the analysis and visualization of a publicly available spatial transcriptomics dataset (10x Genomics Visium) from an FFPE human melanoma tissue sample.

## Overview

The analysis involved loading the dataset, performing quality control, normalization, clustering, and visualizing gene expression patterns (clusters, marker genes, spatially variable genes) in the context of the tissue architecture using Scanpy and Squidpy in Python.

## Key Findings

- Identification of spatially distinct molecular domains corresponding to tumor core and microenvironment regions.
- Characterization of these domains using melanoma and immune cell marker genes.
- Discovery of spatially variable genes highlighting interface biology.

## Data Source

- 10x Genomics Public Dataset: "FFPE Human Melanoma IF-Stained Visium Spatial Gene Expression Dataset"
